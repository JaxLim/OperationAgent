# ADR-SANDBOX-001 Windows 工具沙箱 P3a

2026-11-18 用户授权「M3/P3a 和隔离 runner 验证」。本切片面向 Windows x64 合成工作区，验收服从 ARCHITECTURE §5.3、§13 与 SEC-23。

- 受信启动器在一次性 Windows runner 内为每次调用创建独立 AppContainer。使用受限的主令牌和创建时 Job 归属，暂停创建后检查 AppContainer SID、低完整性等级、无网络能力和 Job 归属。
- 授权根固定为本次测试的合成工作区。运行程序目录可读可执行，工作区外的对照文件受 OS 保护，工作区根的 `.git` 使用受保护的只读 ACL。目录与文件预检拒绝重解析点。AppContainer 自带的私有目录随 profile 清理。
- `write_file` 接受有限字节与工作区根下的普通文件名，创建新文件。Bash 从标准输入读取测试脚本。子进程共享同一 Job 资源上限。超时或主进程退出后收回整棵进程树并检查活跃数量。
- SEC-23 先证明允许的文件写入成功，再检查越界和 `.git` 内容保持原样。默认网络使用有主机正向对照的本地 TCP 监听验证。挂起子进程使用真实 PID 验证回收。缺少可丢弃 runner 时记录 BLOCKED。

P3a 测试产物只在构建和验收阶段使用。现有发布能力门禁继续要求 P3b，届时还需核验真实项目权限、所有敏感路径、网络协议覆盖、审批、工具输出和取消行为。
